3연봉표 생성

← 임용년월일 (숫자만 입력)
직종 선택·경력 입력을 먼저 완료해주세요. 자동 계산: 기본급(호봉표+승급시점)·기말수당·정근수당·직무수당·가계보조수당·교통비·정액급식비·종사자복지수당·장기근속수당(이 병원 근속연수 기준)·가계안정지원비(4·10월)·효도휴가비(설·추석월)·특수업무수당·직급보조수당·균형수당·근골격계질환예방수당·(간호사 3교대 시)교대수당·(간호사·치료사)면허수당. 가족수당·직책수당·조정수당·간호간병통합수당·(3교대 아닌 경우)교대수당·(간호사·치료사 외)면허수당은 빈칸으로 두니 직접 확인 후 입력해주세요. 생성된 파일은 일반 엑셀처럼 자유롭게 수정 가능합니다.

4저장 / 불러오기

"저장"을 누르면 위의 근무경력 입력 내용과 연봉표 생성 패널 입력값이 한 세트로 같이 저장됩니다. 저장한 이력은 이 컴퓨터의 브라우저에만 저장됩니다(다른 PC와 공유되지 않음). 시크릿 모드이거나 브라우저 데이터를 삭제하면 사라질 수 있으니, 중요한 결과는 인쇄 또는 캡처로 별도 보관해 주세요.

저장된 이력

선택 지원자명 저장일시 직종 경력 건수 인정경력 합계
2명 이상 체크하면 경력·연봉을 나란히 비교할 수 있어요 (군경력 유무 등 같은 사람의 다른 버전도 비교 가능).

경력 · 연봉 비교표

연봉 수치는 "연봉표 생성" 패널에 저장된 값(급수·임용일·3교대·면허 등) 기준으로 자동 계산한 추정치입니다. 저장 당시 연봉표 정보가 없는 이력은 경력만 표시됩니다.
※ 계산 방식: 시작일~종료일(말일 기준) 사이 실 근무기간을 연/월/일로 산출 → 일수 15일 이상이면 1개월로 반올림 → 직종·기관종별 인정비율 적용(반올림) → 인정경력 산출.
※ 특례(본원 퇴직후 재취업 / 본원 계약직·인턴 근무 / 본법인 근무 / 대한민국 군인 복무 / 공무원 근무 등)는 100%로 인정됩니다.
※ 대한민국 군 복무 경력은 성별·직종과 무관하게 모든 구분에서 특례(100%)로 동일 적용됩니다.
